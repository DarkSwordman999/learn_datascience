# learn_datascience

Мой личный репозиторий для изучения Data Science и Machine Learning.
Здесь я веду конспекты, выполняю лабораторные работы и делаю практические проекты.

## 📂 Структура (по мере роста)

Пока репозиторий только зарождается. Постепенно будут появляться:

- `notes/` — конспекты по теории (математика, ML, DL).
- `create_neuron/` — первая практика: искусственный нейрон и сеть FeedForward на NumPy.
- `datasets/` — локальные данные (не коммитятся в Git).
- `PROGRESS.md` — журнал обучения (что и когда сделано).
